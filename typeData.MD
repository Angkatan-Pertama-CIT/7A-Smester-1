type data= klasifikasi atau jenis data yang menentukan bagaimana sebuah nilai (value) disimpan dalam memori komputer dan operasi apa saja yang bisa dilakukan pada data tersebut.

Integer= untuk menampung bilangan bulat (positif, negatif, nol) 10, -5, 0

Float/Double= untuk menampung bilangan desimal. 3,14; 0,001; 0,2

String(str)=untuk menampung teks/karakter, harus diapit dengan tanda kutip. ("halo dunia")

Boolean(bool)= hanya memiliki 2 nilai mutlak. True atau false

Array/list= menyimpan kumpulan data menggunakan indeks (urutan). (1,2,3)

Object/dictory= yang menyimpan data berpasangan antara key (kunci) dan value (nilai)

Null/none= tipe data spesial yang menunjukan bahwa sebuah variabel tidak emiliki nilai kosong

Operator= dihgunakan untuk melakukkan perhitungan matematis pada data sensor atau kalkulasi pergerakan roda
          + penjumlahan
          - pengurangan
          * perkalian
          / pembagian
          % sisa bagi
          == sama dengan
          != tidak sama dengan 
          > lebih besar
          < lebih kecil
          = memberikan nilai
          and keduanya benar
          or salah satu benar
          not membalik nilai
