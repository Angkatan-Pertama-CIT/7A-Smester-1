ghithab merupakan version control dari sebuah code
Repository: folder proyek yang menyimpan file riwayat, dan aturan kerja.
Bommit: snapshot perubahan yang diberi pesan agar mudah di lacak.
Brach: jalur kerja terpisah untuk fitur. eksperimen. atau perbaikan.
Gitt branch: untuk melihat branch aktif dan branch yang ada
Gitt clone <url>: ambil repository ke komputer
Gitt status: cek line yang berubah
Gitt checkout<nama branch>: buat dan pindah ke branch baru
gitt agg_: siapkan semua perubahan 
git commit -M "pesan": simpan perubahan sebagai commit 
git push _U origin <nama branch>: push branch baru ke GitHub 
git pull orgin main: ambil perubahan terbaru dari main
