Apa itu variabel? 
Variabel adalah nama untuk menyimpan data di dalam program. Nilainya dapat digunakan tergantung deklarasinya analoginya aku ataupun kamu, mempunyai beberapa kotak penyimpanan.Setiap kotak diberinama dan berisi sesuatu
|nama kotak |isi kotak
|umur       |10 int umur =10;
|nilai      |10 int nilai =10;
|kelas      |5 int kelas =10;
jadi variabel adalah nama untuk tempat menyimpan data dalam program. 
int itu adalah tipe data
umur itu adalah nama variabel
10 itu adalah nilai yang disimpan

parameter adalah variabel yang ditulis pada bagian penerima input suatu fungsi.Parameter membantu fungsi menerima data saat dipanggil.
fungsi merupakan kumpulan perintah yang diberi nama dan dapat dipanggil untuk mengerjakan tugas tertentu.
