1. Tipe data 
Dipakai di semua bahasa pemrograman 
tipe data :              contoh:                  penjelasan:
integer / int          10 , -5 , 2025             bilangan bulat 
float / double         3 , 14 , 0.5               bilangan desimal 
string / str           "hallo" , "ibu"            teks, harus pakai tanda petik
boolean / bool         true/false                 benar atau salah
array / list           {1},{2},{3}                kumpulan data 
object / dict          {"nama"},{"ahmad"}         data berpasangan kunci-nilai 
null / none            null                       kosong/tidak adaa nilai
