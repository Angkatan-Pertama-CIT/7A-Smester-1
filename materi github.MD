github merupakan version control dari sebuah kode.
repository merupakan folder ptoyek yang menyimpan riwayat,dan aturan kerja.
commit merupakan pesan perubahan yang diberi label agar mudah dilacak.
branch merupakan jalur kerja terpisah untuk fitur,eksperimen,atau perbaikan.

git branch:untuk melihat branch aktif dan branch yang ada

git clone <url>:ambil repository ke komputer 

git status:cek file yang berubah

git checkout<nama branch>:buat dan pindah ke branch baru

git add.:siapkan semua perubahan 

git commit -m "pesan":simpan perubahan sebagai commit

git push -u origin <nama branch>:push baru ke github

git pull origin main:ambil perubahaan terbaru dari main
