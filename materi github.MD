github: merupakan versioning control dari sebuah code 
repository: merupakan folder proyek yang file, riwayat dan aturan kerja
commit: merupakan pesan perubahan yang diberi label   agar mudah dilacak
branch: merupakan jalur kerja terpisah untuk fitur experimen atau pembuatan
syntax:
1.git branch          untuk melihat bbranch aktif dan branch yang ada
2.git clone <url>     ambil repository ke komputer
3.git status          cek file yang berubah
4.git checkout <nama branch>     buat dan pindah ke branch baru
5.git add .           siapkan semua perubahan
6.git commit -m "pesan"
7.push -u origin <nama branch>    push branch baru ke github
8.git pull origin main            ambil perubahn terbaru dari main
