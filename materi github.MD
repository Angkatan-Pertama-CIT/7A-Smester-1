github merupakan version control dari sebuah coding

### konsep inti yang perlu dipahami

### Repotorik
folder proyek penyimpanan file,riwayat,dan aturan kerja.
### Commit
snapshot/pesan perubahan yang diberikan pesan agar mudah di lacak.
### Branch
jalur kerja terpisah.
git Branch:untuk melihat branch aktif dan branch yang ada.
git clone <url>:ambil repository ke komputer.
git status:cek file yang berubah.
git checkout <nama branch>:buat dan pindah ke branch baru.
git add:siapkan semua perubahan.
git commit -m "pesan":simpan perubahan sebagai commit.
git push -u origin <nama branch>:push branch baru ke github.
git pull origin main:ambil perubahan terbaru dari main.
