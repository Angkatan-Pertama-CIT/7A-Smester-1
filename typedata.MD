type data = berfungsi sebagai "penerjemah" antara sensor fisik data robot dengan logika program di dalam mikrokontroler.
  contoh : arduino, raspberry pi, atau ESP32

  char= untuk menyimpan karakter atau teks komunikasi data.

  string= untuk menerima perintah teks lewat bluetooth atau menampilkan status ke layar LCD atau menyimpan teks atau nama.

  integer (int) = untuk menyimpan bilangan bulat (angka yang tidak memiliki koma atau pecahan).

  float = bilangan desimal
  string (str) = teks atau kumpulan karakter 

  boolean (bool) = nilai benar atau salah (true atau false).
  caracter (char) = satu karakter "A" atau "7" 
  array atau list = kumpulan beberapa data ( 10,20,30)
  object = data yang memiliki atribut dan nilai.

operator aritmotika = di gunakan untuk melakukan perhitungan matematis pada data sensor atau kalkulasi pergerakan roda.

(+) = menambahkan dua nilai numerik 
(-) = menghitung sisa jarak atau target
(*) = perkalian
(/) = pembagian 
(%) = sisa bagi
