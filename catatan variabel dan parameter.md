variabel dan parameter 
variabel adalah nama untuk menyimpan data dalam program. nilainya dapat di gunakan tergantung deklarasinya, analoginya "aku/kamu", mempunyai beberapa kotak penympanan.
   setiap kotak di beri nama dan di beri sesuatu
   |nama kotak|      |isi kotak|
   |  umur    |      |   10    |
   |  nilai   |      |   10    |
   | kelas    |      |   5     |

   jadi variabel adalah nama untuk tempat menyimpan data dalam program
   -int umur = 10;
   -int nilai = 10;
   -int kelas = 5;
   - tipe data = int dll
   -variabel adalah nama atau (umur,nilai,kelas)
   -nilai yang di simpan =10;
    
    int= tipe data
    umur= variabel
    10; = nilai yang di simpan
    
       parameter = pemanggil
 parameter adalah variabel yang di tulis pada bagian penerima input suatu fungsi.
 parameter membantu fungsi menerima data saat di panggil

     fungsi
 fungsi merupakan kumpulan perintah yang di beri nama dan dapat di panggil untuk mengerjakan tugas atau proses tertentu.

    analogi = mesin pembuat jus 
 memasukan buah pada blender
 mesin menggiling buah 
 mesin menghasilkan jus 

    variabel = buah, blender, gelas
 dalam program, fungsi juga dapat menerima data. memprosesnya, lalu melakukan proses pekerjaan 
   
      fungsi membuat jus
  memasukan buah 
  memproses menjadi jus
  menuang jus ke gelas 
  meminum jus
