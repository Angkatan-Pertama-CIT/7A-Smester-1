variabel
variabel adalh nama untuk tempat menyimpan data didalam program.nilainya dapat digunakan tergantung deklarasinya analoginya aku mempunyai beberapa kotak penyimpanan.setiap kotak di berinama dan berisi sesuatu
|nama kotak  |isi kotak  |
|------------|-----------|
|umur        |10         | <int umur:10
|nilai       |10         | <int nilai:10
|kelas       |5          | <int kelas:5
|------------|-----------|
jadi variabel adalah nama untuk tempat menyimpan data dalam program

parameter
parameter adalah variabel yang ditulis pada bagian penerima input suatu fungsi.parameter membantu fungsi menerima data saat dipanggil

fungsi
fungsi merupakan kumpulan perintah yang diberi nama dan dapat dipanggil untuk mengerjakan tugas tertentu analoginya bayangkan blender
1.masukkan buah ke blender
2.mesin menggiling buah
3.mesin menghasilkan jus
dalam program,fungsi juga dapat menerima data memprosesnya,lalu melakukan suatu pekerjaan
