## Operator dalam Coding (JavaScript)

Operator adalah simbol untuk melakukan operasi pada nilai atau variabel.

### Aritmatika

| Operator | Fungsi | Contoh | Hasil |
|---|---|---|---|
| `+` | Penjumlahan | `8 + 3` | `11` |
| `-` | Pengurangan | `8 - 3` | `5` |
| `*` | Perkalian | `8 * 3` | `24` |
| `/` | Pembagian | `8 / 2` | `4` |
| `%` | Sisa pembagian | `8 % 3` | `2` |
| `**` | Pangkat | `2 ** 3` | `8` |

### Perbandingan

Perbandingan menghasilkan nilai `true` atau `false`.

| Operator | Fungsi | Contoh | Hasil |
|---|---|---|---|
| `===` | Sama nilai dan tipe | `5 === 5` | `true` |
| `!==` | Tidak sama nilai atau tipe | `5 !== "5"` | `true` |
| `>` | Lebih besar | `8 > 3` | `true` |
| `<` | Lebih kecil | `2 < 3` | `true` |
| `>=` | Lebih besar atau sama dengan | `3 >= 3` | `true` |
| `<=` | Lebih kecil atau sama dengan | `2 <= 3` | `true` |

### Logika

- `&&` (AND): benar jika kedua kondisi benar. Contoh: `umur >= 17 && punyaIzin`.
- `||` (OR): benar jika setidaknya satu kondisi benar. Contoh: `hari === "Sabtu" || hari === "Minggu"`.
- `!` (NOT): membalik nilai logika. Contoh: `!sudahLogin`.

### Penugasan

- `=` memberi nilai: `let skor = 10`.
- `+=` menambah lalu menyimpan: `skor += 5` sama dengan `skor = skor + 5`.
- `-=` mengurangi lalu menyimpan: `skor -= 2` sama dengan `skor = skor - 2`.
- `*=` mengalikan lalu menyimpan: `skor *= 2` sama dengan `skor = skor * 2`.
- `/=` membagi lalu menyimpan: `skor /= 2` sama dengan `skor = skor / 2`.

### Operator lainnya

- `++` menambah nilai satu: `skor++`.
- `--` mengurangi nilai satu: `skor--`.
- `+` juga dapat menggabungkan teks: `"Halo, " + nama`.
- `kondisi ? nilaiJikaBenar : nilaiJikaSalah` memilih nilai berdasarkan kondisi.

Contoh penggunaan:

```js
let harga = 10000;
let jumlah = 3;
let total = harga * jumlah;
let diskon = total >= 30000;

console.log(total); // 30000
console.log(diskon); // true
```
